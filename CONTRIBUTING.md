# Contributing to MeetingPal

Use the [development guide](docs/DEVELOPMENT.md) to build and test a change. Use synthetic recordings when reporting bugs and keep credentials and personal meeting data out of issues and pull requests.

MeetingPal's own code is licensed under [AGPL-3.0-only](LICENSE). Before your first contribution is merged, read the [Individual Contributor License Agreement](CLA.md) and accept it in a comment on your pull request with the following text.

> I have read the CLA Document and I hereby sign the CLA

Maintainers can refer to that pull request for subsequent contributions. Identify the source and license of any third-party material you include.
